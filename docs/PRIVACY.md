# 数据与隐私说明

本说明适用于 LanBoost 0.5.0。

## 本机数据

- 节点列表、完整库缓存、来源和更新时间、获取错误、测速结果、选用 IP、每组筛选条件和设置保存在应用私有存储中。
- DNS 与 HTTP 活动记录保存在进程内存中，部分诊断信息也写入 Android 系统日志。记录可能包含客户端内网地址、请求域名和选用节点。
- 应用不要求账号登录，当前版本没有应用自建的统计上报或云端同步功能，且关闭了 Android 应用数据备份。

卸载会移除应用私有数据；系统日志是否保留由 Android 管理。分享诊断日志或截图前，应遮盖设备标识、网络地址、Wi-Fi 名称以及链接中的令牌或个人路径。

筛选使用节点库已有标签，不请求 IP 地理定位服务，也不读取手机定位。

## 网络请求

| 操作 | 请求发送到哪里 | 接收方可获得的信息 |
| --- | --- | --- |
| 获取在线节点 | XboxDownload 的 GitHub Raw / GitHub API 公共列表 | 请求来源公网地址和常规 HTTP 请求信息 |
| 普通域名解析、候选解析回退 | 设置中的上游 DNS 服务器 | 请求域名和网络来源信息 |
| 节点测速 | 选定的 CDN 节点和测试链接对应的服务 | 请求来源地址、Host、路径及其他常规请求信息 |
| 局域网 DNS / HTTP 换源 | 同一子网中主动连接手机的客户端 | App 读取 DNS 查询或 HTTP 请求，返回解析结果或跳转地址 |

获取节点使用系统当前网络（可能包括移动网络及适用的代理/VPN）；每次请求最多 1 MiB，每轮最多三次请求。测速使用 Wi-Fi。测速内容读入后丢弃，不作为游戏下载文件保存。部分默认测试使用 HTTP；HTTPS 请求保持证书校验。上述第三方服务各自处理其收到的请求，应用不控制它们的日志保存规则。

## Root 的用途

Root 用于建立和清理本应用的 `LANBOOST_IN` 端口转发规则，将发往手机的局域网 DNS/HTTP 请求交给应用监听端口。应用不更改系统 DNS 或路由器配置。服务需要同子网访问，不需要开放路由器公网端口。

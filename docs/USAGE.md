# LanBoost 0.5.0 · 多平台 DNS

此版增加运营商、省份 / 地区、城市与关键词组合筛选，并可选择测完筛选结果；国内 HTTP 换源仍默认开启，保留 Xbox、NS、PS、EA、战网国际服和其他 Akamai CDN 九组。范围是「获取候选 → 测速/测延迟 → 指定 IP → 局域网 DNS」，不下载游戏到手机、不做商店浏览或文件回传，也不提供游戏联机代理。

同签名的 0.5.0 可以覆盖安装旧版本，保留原有设置。全新安装或尚未保存换源设置时默认开启；已有的手动开启/关闭状态不变。各组的候选、结果和选用 IP 分别保存。

## 分组与原项目的对应

| 分组 | 节点来源 | 默认测速与 DNS 范围 |
| --- | --- | --- |
| CN1 | XboxCn1 | Xbox 国内主下载域名 |
| CN2 | XboxCn2 | Xbox 部分旧游戏下载域名 |
| COM | Akamai | Xbox 国际下载域名 |
| 应用 | XboxApp | 微软商店应用及部分 PC 游戏，包括 `*.tlu.dl.delivery.mp.microsoft.com` |
| NS | Akamai | Switch 内容、更新及测试域名；含原项目 Switch 1/2 内容域名后缀 |
| PS | Ps 独立节点库 | `gst.prod.dl.playstation.net`、`gs2.ww.prod.dl.playstation.net`、`zeus.dl.playstation.net`、`ares.dl.playstation.net` |
| EA | Akamai | `origin-a.akamaihd.net`，默认用 EA 安装文件做有上限的测速 |
| 战网 | Akamai | `blzddist1-a.akamaihd.net`、`downloader.battle.net`，针对国际服下载 |
| 其他 CDN | Akamai | 原项目 Epic、育碧、Riot、Steam 静态资源及通用 Akamai 域名规则 |

PS、NS、EA 使用各自的参考测速文件，不套用 Xbox 文件测速结果。应用、战网和其他 CDN 没有内置稳定测试文件，默认仅测 TCP 80 端口延迟；设置中填入本组有效 HTTP/HTTPS 下载链接后可测吞吐。

## 节点库与测速

- 获取列表跟随手机当前可用网络，可使用适用于本应用的系统代理或 VPN；这一步也可能使用移动网络。节点测速和 DNS/HTTP 服务仍使用 Wi-Fi。
- 获取顺序为 GitHub Raw → GitHub API，瞬时网络错误最多额外重试一次；每次请求最多 10 秒、1 MiB。完整库按平台缓存，失败不会清空原有结果。
- 「完整节点库」表示成功取得官方列表；「使用缓存」表示本次更新失败、继续使用上次完整库；「DNS 临时候选」表示尚无完整库，只取得下载域名的少量解析结果。点击「获取详情」查看错误，点击「获取节点」重试。
- 总节点数可能大于完整库数量：已导入、DNS 候选、已测速或选用的旧节点会保留。列表展示总数、筛选数量和当前链接已测数量；每页最多 60 项，可翻页查看。
- 「继续测试下一批」跳过已尝试当前测速链接的节点，保留已有结果；失败的下载尝试也会跳过。需要重测时用「开始测速」。更换测速链接后，旧结果不会计入新链接已测数量。
- 运营商、省份 / 地区、城市和关键词同时生效。可只选运营商或省份；选择省份后才可选择城市，换省份会清空城市。关键词用空格分隔时需全部匹配。各平台分别记住筛选，点击「清空筛选」恢复全部。
- 筛选依据节点库已有文字标签，不查询 IP 定位、不读取手机位置，也不保证标签实时准确。电信/联通等多线标签同时归入相应运营商；缺少或不能识别的标签归为「未标注」，识别到的海外节点归为「境外」。可用关键词补充筛选。
- 「开始测速」确认框默认选「本批最多 12 个」，批量大小可在设置中改为 1–50；也可选择「测完筛选结果」，逐个测试全部可达候选，不受每批数量限制。确认框显示范围、数量和测试数据上限，数量较多时需要更长时间，可随时取消。
- 「继续测试下一批」同样可选择本批或测完剩余节点。节点列表、测速、继续测速和「采用最快 / 采用低延迟」使用同一筛选范围。筛选不会自动改变已选用的 DNS 节点；修改选用节点前仍需停止 DNS 服务。

**NS 实测限制：**已测网络对原项目的 `http://ctest-dl-lp1.cdn.nintendo.net/30m` 返回 HTTP 403。HTTPS 版本出现证书信任错误，另一个旧测试域名未解析出 IPv4，因此没有宣称 NS 默认吞吐测速通过。DNS 映射已通过协议测试。可以换成有效的任天堂下载链接，或在设置清空测速链接后先测延迟、手动选 IP。没有关闭 HTTPS 证书校验。

「其他 CDN」可能影响匹配的非游戏 Akamai 资源，选用 IP 后才启用。Steam 条目只覆盖商店静态资源和视频，不代表支持 Steam 游戏仓库下载加速。各平台独立分组优先于通用规则，即便该平台当前未指定 IP；自定义精确域名规则优先级最高。

## 配置手机与客户端

1. 手机和主机/电脑连接同一非隔离局域网，路由器无需刷机。建议为手机设置固定 DHCP 租约。
2. 在 Root 管理器中给 **LanBoost** 授予超级用户权限，在 App「DNS 服务」下方检查 Root。ADB shell Root 与应用授权相互独立。
   - 部分系统会冻结后台服务。请在应用耗电管理中允许后台运行；系统支持时可在最近任务中锁定 App。前台通知存在不代表 DNS 一定可用，遇到超时可重新打开 App 检查服务状态。Android 16 在允许后台、最近任务加锁和 USB 充电条件下，约四分钟锁屏期间的四轮检查通过；长时间待机、未充电及其他机型尚未验证。
3. 「节点优选」选择平台 → 获取节点或导入文本 → 可按运营商 → 省份 / 地区 → 城市筛选 → 测速 → 点击结果或「采用最快」。空测速链接对应「采用低延迟」。
4. 「DNS 服务」点击对应规则可以手填 IP、查看全部域名、调整备用域名屏蔽，或「自动解析」清除该组选用 IP。修改前先停止服务，修改后重新启动。
5. 国内 HTTP 换源默认开启，选好 CN1 节点后生效；未选 CN1 时普通 DNS 和其他平台仍正常工作。随后启动 DNS，把设备主 DNS 填为 App 显示的手机地址。地址以 App 实时显示为准。副 DNS 留空；设备强制要求填写时用相同手机地址，避免公共 DNS 绕过规则。
6. 暂停再继续下载，在「活动」查看来自主机的域名请求、返回 IP 和屏蔽记录。没有新请求可能是缓存或旧连接，可以重启主机重试。
7. 停止服务或手机离开 Wi-Fi 前，将设备 DNS 恢复自动。

| 设备 | 设置入口提示 |
| --- | --- |
| Xbox | 网络设置 → 高级设置 → DNS 设置 → 手动 |
| Nintendo Switch | 互联网 → 互联网设置 → 当前网络 → 更改设置 → DNS 设置 → 手动 |
| PlayStation | 设置互联网连接 → 当前网络/高级设置 → DNS 设置 → 手动；具体菜单随 PS4/PS5 系统版本略有区别 |
| PC 平台 | 修改电脑当前网卡的 DNS，填手机地址；安装 Android App 不会自动修改电脑网络 |

## Xbox 下载慢时确认入口

如果活动中出现 `assets1.xboxlive.com` 等国际下载域名，仅选好 CN1 不会自动把纯 DNS 模式的 COM 下载变成国内下载。确认「国内 HTTP 换源」开启且已选 CN1，重新启动服务，再暂停/继续下载；日志应出现 HTTP 307，以及 `assets1.xboxlive.cn` 请求。旧版本升级后若仍显示换源关闭，可在设置手动开启。短样本测速不代表实际游戏吞吐，按主机显示的持续速度判断。

原项目的 Xbox SRV 调度屏蔽策略仍未移植到此版。实际下载收益需要按当前网络和游戏测量。

## 备用下载域名屏蔽

NS、EA、战网延续原项目的备用 CDN 屏蔽名单。仅在本组选了 IP 且勾选「屏蔽备用下载域名」时生效，返回 `0.0.0.0`，同时不给出 IPv6 地址或 HTTPS/SVCB 提示，避免备用地址绕过选用节点。默认勾选，可在规则详情关闭；下载异常时可关闭作对照。恢复自动解析后，该组屏蔽也停止。

- NS：`atum-eda.hac.lp1.d4c.nintendo.net`、`atum-4ff.hac.lp1.d4c.nintendo.net`。
- EA：`prod.cloudflare.cdn.ea.com`、`ssl-lvlt.cdn.ea.com`。
- 战网：`level3.ssl.blizzard.com`。

战网的其他 CDN HTTP 换源没有移植到此版；当前实现的是上述 DNS 选址与可选屏蔽。Xbox 国内 HTTP 换源默认开启，可在设置中关闭；选好 CN1 节点后才生效，旧游戏下载换源还需选好 CN2。只针对支持的 Xbox HTTP 下载，不适用于 NS/PS。相关 HTTPS 请求可能失败，因为手机不提供 HTTPS 中转。

## 测速与服务行为

- 先用 6 个工作线程测筛选范围内的 TCP 连通性，再按延迟顺序逐个测吞吐。默认本批最多 12 个、每节点最多 5 秒 / 32 MiB，测试数据上限 384 MiB；选择测完筛选结果时，上限按筛后待测数量计算。时长、每批数量和单节点流量可在设置调整。
- 测试流量只走手机 Wi-Fi，数据读入后丢弃。保留原始 Host 和 TLS 证书校验，不把错误页或跳转当成功样本。
- 低延迟不等于高吞吐；短样本不代表实际下载速度。具体游戏缓存、运营商和主机网络都会影响结果。
- 在线列表来自 XboxDownload 公共 IP 文件；Raw/API 均失败时优先使用完整缓存，没有缓存时才尝试解析当前组测试域名的少量候选。可粘贴或导入文本，每行一个 IPv4，可附运营商/地区。
- 支持 UDP/TCP 53。普通域名转发给主 DNS `223.5.5.5`，超时、无效应答、SERVFAIL/REFUSED 时用备用 `119.29.29.29`。备用可改或留空，NXDOMAIN 等有效负结果不会重试。
- 「优先 IPv4」仅抑制已映射域名的 AAAA/HTTPS/SVCB，不关闭整个网络的 IPv6。
- Root 只创建本应用 `LANBOOST_IN` 链和跳转，将同子网发往手机 Wi-Fi 地址的 53 端口转到 App 1053；没有修改手机和路由器的系统 DNS 或其他防火墙规则。
- 服务有前台通知与 CPU/Wi-Fi 锁。Wi-Fi 断开或地址改变会停止；长期后台运行仍可能受 ROM 电池管理影响。
- 停止服务会清理规则，外部 Root 看守尝试在应用进程退出后清理。异常时可点「清理端口规则」或重启手机。
- 活动记录保留在内存，设置和节点保存在手机本地，无账号登录。连接诊断可检查 Wi-Fi、上游和本机监听。

## 构建与参考

JDK 17、Android SDK 35；最低声明 Android 8.0。自行构建的 APK 使用本机调试签名，只有签名一致时才能覆盖安装。源码不包含签名私钥、本机路径或构建缓存。

```sh
./gradlew :core:test :app:assembleDebug :app:lintDebug
```

这是独立实现，不是官方移植或原项目全部功能的等价替代。域名、参考测速 URL 与列表来源核对自 [XboxDownload](https://github.com/skydevil88/XboxDownload) 提交 `9acd0cde323636dd54bd0bfcef2297bed306a314` 的 `DnsMappingGenerator.cs`、`Resources/Akamai.txt`、`SpeedTestDataBuilder.cs` 和 `IP/`。构建、测试与依赖信息见 [开发说明](DEVELOPMENT.md)，签名与自动发布见 [签名说明](SIGNING.md)。
